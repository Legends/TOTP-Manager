# Project asset provenance

This record covers every raster image embedded by `TOTP.UI.Avalonia.Desktop`. The files are project-owned outputs and are distributed under the repository's [MIT license](../../LICENSE.txt). No downloaded raster artwork is included.

## Application icon

The application icon was generated specifically for TOTP Manager on 2026-08-29 using OpenAI's built-in image-generation tool at the maintainer's request. It was generated without an input or reference image, so the unknown earlier icon was not used as source material. The generated master was resized with high-quality bicubic interpolation; the ICO packages independently resized PNG frames at 16, 24, 32, 48, 64, 128, and 256 pixels.

Final generation prompt:

> Use case: logo-brand. Asset type: original desktop application icon for an open-source TOTP authenticator. Create a clean, distinctive icon representing time-based one-time passwords and a secure local vault. Use a simple circular clock face integrated with a small shield/keyhole motif as one unified symbol. Use polished modern desktop-icon styling, vector-friendly geometric forms, a centered bold silhouette, generous padding, and a rounded-square tile with transparent pixels outside it. Use deep navy and cool teal with a restrained warm amber clock-hand accent. Include no text, letters, numbers, QR code, brand logos, watermark, signature, or very fine detail. Create entirely original artwork in a square format.

The generated image was visually reviewed for prohibited text, third-party branding, and small-size legibility before conversion.

## Language flags

`en.png` and `de.png` were rendered inside the project workspace on 2026-08-29 from geometric primitives. They do not derive from downloaded image files:

- `en.png` is a project-rendered representation of the public-domain United States flag design, used for the English locale.
- `de.png` is a project-rendered representation of the public-domain German federal flag design, used for the German locale.

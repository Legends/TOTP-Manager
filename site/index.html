Open source · Local first · No cloud account

Your authentication codes stay yours.

OTP Harbor is a native TOTP and 2FA authenticator with an encrypted local vault, quick unlock, QR workflows, and portable encrypted backups.

Microsoft Store — coming soon View source on GitHub

The Microsoft Store is the planned primary Windows channel. Current GitHub packages are explicitly labeled manual previews.

Encrypted locally

OTP seeds are protected in a local AES-256-GCM vault derived from your master password with Argon2id.

Fast daily use

Scan QR codes, search accounts, copy current codes, and use platform quick unlock with password recovery.

Portable recovery

Create encrypted backups that can be restored across supported OTP Harbor platforms.

Trust through evidence

Security is part of the release process.

The repository publishes its threat model, recovery guidance, security verification evidence, release controls, and private vulnerability-reporting path.
